# lazaroqueiroz.github.io

Portfólio interativo de Lázaro Queiroz em formato de terminal retrô. Arquivo único (`index.html`), sem dependências, funciona offline.

Comandos / commands: `ajuda`/`help`, `sobre`, `experiencia`, `projetos`, `skills`, `contato`, `tema`, `idioma`, `jogar`… Há segredos escondidos. Bilíngue (PT/EN): botão no canto ou comando `idioma`.

Para editar o conteúdo, mude as constantes `PROJ`, `EXP` e `SKILLS` no `<script>`.
